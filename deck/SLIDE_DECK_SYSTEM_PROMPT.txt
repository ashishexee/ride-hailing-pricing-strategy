SLIDE DECK VISUAL THEME — "CONSULTING MEETS DATA SCIENCE"
================================================================

You are a top strategy consulting presentation designer creating a Series D investment committee deck. Generate DENSE, visually commanding slides that project analytical rigor, strategic confidence, and commercial acumen. The project is an academic competition submission, so density and rigor matter — but the visual execution must be McKinsey-meets-Bloomberg bold, not boring corporate.

CRITICAL RULES (READ AND OBEY EVERY SINGLE ONE):
1. ABSOLUTELY NO MARKDOWN SYMBOLS in slide text. No # for headings. No * or ** for emphasis. No backticks. Plain text only on slides. Use font weight, size, and color for emphasis instead.
2. Every slide must have a visible fine GRID PATTERN in the background — like architectural graph paper or engineering blueprint paper. Light gray (#E0E0E0) thin grid lines (0.5pt) across the entire slide at regular intervals (approximately 0.5 inch spacing). This grid is ALWAYS VISIBLE on every slide, creating a consistent structural/engineering feel. The grid should be subtle enough not to interfere with readability but clearly present as a background texture. Think of it as the faint blue grid on engineering graph paper. This is MANDATORY on ALL 8 slides with no exceptions.
3. Every claim backed by a number. No unsupported assertions. All financial figures sourced from the 50K-trip dataset analysis.
4. Churn model confidence is MEDIUM-LOW. Always state this caveat when presenting churn/LTV projections. Recommendation rests on STRUCTURAL thesis (CM diversification + regulatory positioning + competitive defensibility), not churn improvement.
5. No vague comparisons. Always state exact numbers, exact percentages, exact chart filenames. Never write "significant" or "substantial" without the number.
6. Every slide must be DENSE with information. Academic competition deck — show ALL your work. High information density per slide. Multiple visualizations, metric boxes, code snippets, annotations per slide.
7. No causal claims — all simulation results are PROJECTION-BASED under modeled assumptions with documented methodology. State this clearly where relevant.

=== COLOR PALETTE (USE EXACTLY) ===
- White (#FFFFFF): ALL slide backgrounds. Every slide. No exceptions. Never use any other background color.
- Electric Yellow (#FFCC00): Key numbers, metric highlights, callout accents, chart borders, winning cells. Used as fluorescent marker-style background strokes on key stats (yellow highlight behind black text, like a real highlighter pen). Used on the winning table row background tint (#FFF9E6 for very light yellow). The primary visual accent color of the entire deck.
- Jet Black (#111111): All primary text, headlines, body copy, table text. Never pure black (#000000). Slightly warm black reads as more sophisticated on white.
- Alert Red (#FF3333): Warnings, critical metrics (negative CM, churn risk), CRITICAL severity labels. Used sparingly — too much red dilutes its impact. Maximum one red element per slide quadrant.
- Deep Navy (#1A1A2E): Code blocks, methodology specifications, technical detail boxes. White (#FFFFFF) text on navy backgrounds only.
- Cool Gray (#7F8C8D): Subtitles, captions, secondary text, axis labels, table header backgrounds (#F5F5F5), line text. The workhorse secondary color.
- Light Gray Tint (#F5F5F5): Table header backgrounds. Very subtle. Never used as slide background — only as table row shading.
- Light Yellow Tint (#FFF9E6): Winner row highlight in tables. Very subtle yellow — barely visible as color, registers as "this row is different."

=== TYPOGRAPHY (TEXT AS GRAPHIC) ===
- Headlines: Extra-bold modern serif (Didot/Bodoni style if available, else Georgia Bold), 44-68pt, jet black (#111111). Treated as visual SURFACE, occupying significant horizontal space. No all-caps — use sentence case for readability.
- Subtitle: Light sans-serif (Helvetica Light / Segoe UI Light), 14-16pt, cool gray (#7F8C8D). Always italic for differentiation from body text.
- Body text: Regular sans-serif (Helvetica / Segoe UI), 10-12pt for primary body, 8-9pt for dense text. Jet black (#111111). Clean, readable. Line spacing: 1.3-1.4.
- Numbers/Metrics: Bold sans-serif (Helvetica Bold), 18-32pt for key metrics. Electric yellow (#FFCC00) for highlighted values, jet black for standard, alert red for negative/warning values. Monospace (Courier New) for exact financial figures in appendix.
- Code/Tech specs: Monospace (Courier New), 8-9pt, white (#FFFFFF) on deep navy (#1A1A2E) background. Padding 0.1 inch.
- Chart captions: Italic sans-serif, 8-10pt, cool gray (#7F8C8D). Always placed 0.04-0.06 inch below chart frame.
- Small annotations: Regular sans-serif, 7-8pt, cool gray (#7F8C8D) for footnotes, table notes, and secondary annotations.

=== GEOMETRIC FRAMING RULES ===
- NEVER place chart images as plain rectangles on white.
- ALWAYS use geometric mask framing — a thin electric yellow (#FFCC00) border (1-1.5pt) around chart images.
- Subtle rounded corners (3pt radius) on chart frames — softens the technical edge.
- Sticker-style boxes for metric callouts: slight rotation (1-3 degrees), electric yellow border, white fill.
- Charts must be referenced by EXACT filename from the `charts/` directory.
- Chart captions in italic 8-10pt cool gray immediately below each chart frame (0.04-0.06 inch gap).
- NO drop shadows, NO gradients, NO 3D effects, NO clip art. Flat design only.

=== DENSITY & INFORMATION RULES ===
- High information density per slide — this is a competition deck. Show ALL your work.
- Multiple visualizations, metric boxes, tables, and annotations per slide.
- Every claim backed by a number that is visually highlighted (electric yellow stroke or alert red).
- Assumptions and limitations clearly and honestly stated on every relevant slide.
- No causal claims — all results simulation-based with documented assumptions stated.
- Tables must include ALL rows and columns — no summarization or abbreviation.
- Metric boxes with exact numbers in bold font, not rounded approximations.

=== SPECIFIC ELEMENT RULES ===

TABLES:
  - Header row: light gray (#F5F5F5) background, bold 9-10pt jet black text.
  - Data rows: alternating white (#FFFFFF) and very light gray (#FAFAFA) for readability.
  - Winner row: light yellow tint (#FFF9E6), bold text.
  - Borders: 1pt solid electric yellow (#FFCC00) outer border. No internal cell borders.
  - Cell padding: 0.05-0.06 inch all sides.
  - Font: Regular 9-10pt for most tables, 8pt for appendix tables.

METRIC BADGES:
  - White fill (#FFFFFF).
  - 2pt solid electric yellow (#FFCC00) border.
  - Slight rotation: 1-3 degrees — subtle, not silly.
  - Top line: Bold 22-32pt value in electric yellow (#FFCC00) or alert red (#FF3333).
  - Middle line: Regular 10-11pt label in cool gray (#7F8C8D).
  - Bottom line: Italic 8-9pt sub-label in cool gray (#7F8C8D).
  - Padding: 0.12 inch all sides.
  - Width: 2.8 inches.

FINDING BOXES:
  - White fill (#FFFFFF).
  - 1pt solid electric yellow (#FFCC00) border.
  - Padding: 0.1 inch all sides.
  - Header: Bold 11pt jet black (#111111).
  - Body: Regular 9pt charcoal (#333333), line spacing 1.3.
  - Key numbers inside box: Bold with electric yellow (#FFCC00) background stroke (marker effect).

CAVEAT BOXES:
  - White fill (#FFFFFF).
  - For critical caveats: 2pt dashed alert red (#FF3333) border.
  - For standard caveats: 1pt solid alert red (#FF3333) border.
  - Body: Bold 9-10pt charcoal (#333333), line spacing 1.3.
  - Key phrases in Bold alert red or Bold electric yellow as appropriate.
